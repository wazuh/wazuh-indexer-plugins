## `wazuh-threatintel-sigma-filters` index data model

### Fields summary

The fields are based on the [Sigma filters specification](https://github.com/SigmaHQ/sigma-specification/blob/main/specification/sigma-filters-specification.md), stored in the Content Manager content shape, as designed in [#1776](https://github.com/wazuh/wazuh-indexer-plugins/issues/1776). The filter's selections are stored as sent and are not indexed.

The detail of the fields can be found in csv file [Sigma Filters Fields](fields.csv).
